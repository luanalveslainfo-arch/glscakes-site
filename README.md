# Home Treats by Narmatha — Interactive Custom Cake & Dessert Menu

High-end interactive ordering web application for **Home Treats by Narmatha**, custom cake specialist serving Frisco, TX and surrounding areas.

## Features

- **Visual Identity**: Luxurious pastel watercolor palette, subtle gold accents, and elegant serif headings matching brand flyers.
- **6 Official Dessert Options**:
  1. Custom Cakes (Starting at $85.00) with real cake showcases (Winnie the Pooh, 10th Anniversary Roses, Toy Story, Hot Air Balloon & Teddy Bear).
  2. Cupcakes (Starting at $35.00/dozen).
  3. Brownies & Bars (Starting at $30.00/batch).
  4. Cakesicles (Starting at $40.00/dozen).
  5. Dessert Cups & Mini Treats (Starting at $45.00).
  6. Themed & Personalized Desserts (Decorated Sugar Cookies, Cake Pops, Macarons, etc.).
- **Live Order Builder & Steppers**: Multi-item cart with live price calculations and real-time add/remove steppers.
- **50% Deposit Breakdown**: Automatic calculation of 50% reservation deposit and remaining 50% balance upon delivery/pickup.
- **WhatsApp Integration**: Instant, pre-formatted order details sent directly to Narmatha at `+1 (469) 660-6156`.
- **Mobile First**: 100% responsive layout with ergonomic touch controls and full-screen lightbox photo preview.

## Local Development

```bash
npm install
npm run dev
```

## Configuration

Product catalog, pricing, flavors, and baker contact details are managed in `app/configuracao.ts`.
