# Glscakes — cardápio interativo

Site responsivo para montar encomendas de bentô cakes, bolos, kits festa e docinhos.

## O que está incluído

- Catálogo completo da Glscakes.
- Montagem de bolo por tamanho, acabamento, massa, recheios e adicionais.
- Carrinho com múltiplos itens.
- Cálculo automático do total, sinal de 50% via Pix e saldo de 50% na entrega.
- Envio do pedido formatado para o WhatsApp `(21) 96499-9184`.
- Layout otimizado para celular.

## Rodar localmente

```bash
npm install
npm run dev
```

## Personalização

Os produtos, preços e WhatsApp ficam centralizados em `app/configuracao.ts`.
